# 2020 Flavor Wheel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the flavor-wheel lexicon with an exact copy of the 2020 wheel, and clear the old saved notes.

**Architecture:** The lexicon is data (`content/lexicon.json`). The backend indexes it in `tasting/content.py`, and the frontend gets it from the content endpoint, so most of the work is the data file, the tests and fixtures that use old keys, and one Alembic data migration. Unfinished tastings saved on a device drop unknown tag keys when they're restored.

**Tech Stack:** Flask, SQLAlchemy, Alembic (SQLite and Postgres), pytest, React 19, Vitest.

**Spec:** `docs/specs/2026-11-20-2020-wheel-design.md`. Its "The wheel" table is the term list, and its Decisions section fixes casing, slashes, slugs and the version bump.

## Global Constraints

- Words, grouping and order come exactly from the English PDF (©2020): the publisher's English PDF, linked from the page the README's Flavor wheel section points to. If the PDF differs from the spec table, the PDF wins.
- Family and group labels are in title case, and notes are in lowercase. Slashes have spaces around them: "Apple / Pear", "licorice / anise".
- Family slugs: `fruit`, `chocolate`, `sweet`, `nut`, `grain`, `roast`, `spice`, `savory`, `vegetal`, `floral`.
- Family colors are Open Palate's own, not the publisher's hexes, and must keep labels readable.
- `lexicon.json` `version` becomes `2`. `defects`, `preps`, `kinds`, `processes` and `roasts` are unchanged.
- Spec invariants must not regress: blind stays blind, reveal returns 409 while open, consensus needs 3, one read per cup.
- No cupping-sheet publisher name anywhere. `tests/tasting/test_content.py` scans for it.

## Review Focus

1. **A restored draft holding old keys** (`Fruity>Berry>blueberry`) must open without errors and submit without a 400. Covered in Task 3.
2. **A paper sheet that says "cherry" or "Cherry"** must scan to `Fruit>Stone Fruit>cherry`. Covered in Task 1 (`test_scan_label_lookup_new_wheel`).
3. **Taking a group as is** (`Fruit>Citrus`) must still be accepted and shown. Covered in Task 1 (`test_group_key_is_a_term`) and Task 3 (the existing picker centre-tap test, updated).
4. **A label with a slash or apostrophe** ("licorice / anise", "baker's chocolate") must round-trip through save, consensus and search. Covered in Task 1 (`test_slash_and_apostrophe_terms_round_trip`).
5. **Running the migration on a database that has sample data** must leave `tasting_tags` empty and every other table intact. Covered in Task 2.

def test_ten_families_in_wheel_order(self, lex):

def test_term_counts_match_the_2020_wheel(self, lex):
    tiers = {}
    for info in lex.term_index.values():
        tiers[info["tier"]] = tiers.get(info["tier"], 0) + 1
    assert tiers == {1: 10, 2: 89, 3: 43}
    assert sum(1 for v in lex.term_index.values() if v["leaf"]) == 124

def test_fruit_groups_in_order(self, lex):
    fruit = lex.lexicon["tree"][0]
    assert [g["label"] for g in fruit["children"]] == [
        "Citrus", "Apple / Pear", "Melon", "Grape", "Tropical Fruit",
        "Stone Fruit", "Berry", "Dried Fruit"]

def test_leaf_and_heading_flags(self, lex):
    assert lex.term_index[f"Fruit{SEP}Berry{SEP}blueberry"] == {
        "label": "blueberry", "family": "fruit", "tier": 3, "leaf": True,
        "path": ["Fruit", "Berry", "blueberry"]}
    assert lex.term_index[f"Nut{SEP}hazelnut"]["tier"] == 2
    assert lex.term_index[f"Nut{SEP}hazelnut"]["leaf"] is True

def test_slash_and_apostrophe_terms_round_trip(self, lex):
    for key in (f"Spice{SEP}licorice / anise", f"Chocolate{SEP}baker's chocolate",
                f"Floral{SEP}rose / rosewater"):
        assert lex.is_valid_term(key) and len(key) <= 80

def test_families_have_slugs_hex_and_tint(self, lex):
    assert set(lex.lexicon["families"]) == {"fruit", "chocolate", "sweet", "nut", "grain",
        "roast", "spice", "savory", "vegetal", "floral"}
    assert all({"hex", "tint"} <= set(v) for v in lex.lexicon["families"].values())

def test_no_old_wheel_jargon(self, lex):
    labels = {v["label"] for v in lex.term_index.values()}
    assert not labels & {"butyric acid", "vanillin", "Overall sweet", "Other fruit"}
